# Focal study tracker
1. Supabase: create project, run `supabase.sql` in the SQL Editor.
2. Upload these files to a private GitHub repo.
3. Vercel: import repo, add env vars VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY, deploy.
4. Supabase > Authentication > URL Configuration: set Site URL + Redirect URL to your Vercel link.
